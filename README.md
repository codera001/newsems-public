
# SMS Messaging Platform

A web-based SMS messaging platform that allows users to send SMS messages from different locations using a phone number registered on the platform or a rented number.

## ✨ Features

- **User Authentication:** User registration and login.
- **SMS Messaging:** Send SMS messages through the platform.
- **Phone Number Management:** Use a registered phone number or rent a number through the platform.
- **Record Management:** Create, edit, and delete records.
- **Search and Filtering:** Find records efficiently.
- **Administrative Dashboard:** Manage platform activities through a dashboard.
- **API Integration:** Connect frontend functionality with backend services.

## 🛠️ Tech Stack

- **Next.js** — Application framework
- **React** — User interface development
- **Node.js and Express** — Backend development
- **Redux** — Application state management
- **REST API** — Communication between application components and backend services

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Access to the project's required environment variables and API configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/codera001/newsems-public.git
   ```

2. Navigate to the project directory:

   ```bash
   cd newsems-public
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables according to the project configuration.

5. Start the application using the development command specified in `package.json`.

   ```bash
   npm run dev
   ```
